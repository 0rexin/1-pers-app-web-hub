## **BRAIN**
EVERYTHING LANDS IN `inbox/` FIRST — SORT LATER, NEVER WHILE CAPTURING.

- `inbox/` — scribbles from the hub, one file each, named by time.
- `notes/` — things worth keeping, one idea per file.
- `projects/` — has an end. `areas/` — never ends. `resources/` — reference. `archive/` — done.
- Every save from the hub is a git commit here, so nothing is ever lost.

*CAREFUL: this folder is its own local git repo and is ignored by the public fannyhub repo — it has no backup until you give it a private remote.*
